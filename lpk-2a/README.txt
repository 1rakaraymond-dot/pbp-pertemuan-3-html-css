LKP 2A - HALAMAN PROFIL PRIBADI

Isi folder:
- index.html       : struktur halaman dengan HTML5 semantik
- style.css        : styling eksternal, Flexbox, dan CSS Grid
- assets/foto.jpg  : gambar profil sementara (ganti dengan foto milik sendiri)

SEBELUM DIKUMPULKAN
1. Ganti assets/foto.jpg dengan foto profil sendiri. Pertahankan nama file foto.jpg.
2. Buka index.html dan sesuaikan nama, program studi, deskripsi, serta daftar keahlian bila diperlukan.
3. Ganti email@example.com dengan alamat email aktif.
4. Uji tautan navigasi dan tampilan di browser.
5. Ambil screenshot halaman dan simpan, misalnya sebagai screenshot-profil.png.

PROYEK INI TIDAK MEMERLUKAN npm install atau server khusus.
Cukup buka file index.html di browser.
